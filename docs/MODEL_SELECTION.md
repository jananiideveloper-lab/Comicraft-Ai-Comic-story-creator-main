# Activity 1.1 - Model Selection
Requirements: structured panel outlines, narration/dialogue, and comic illustrations.
The supplied design assigns Gemini Flash to structured outlines, Gemini Pro to detailed narration/dialogue, and Stable Diffusion to illustrations.
Implementation note: the document's Gemini 1.5 IDs are legacy; this runnable project uses current Gemini 3.8 Flash for text generation. Stable Diffusion model name from the document is retained in `.env.example`.
